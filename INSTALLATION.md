# Installation

This application runs as a local web app. After it has loaded once, it continues to work with Wi-Fi or Ethernet disconnected because all data and document generation happen on the device.

## Using the live app

1. Open the application.
2. Complete the first-run setup (company, logo, currency, numbering). You may skip optional steps.
3. Add customers and catalogue items, then create quotations and invoices.

## Backup files

Use **Backup** to download `OtravaBackup_YYYY-MM-DD_HHMM.json`. Store that file on a USB drive or another folder you control. Restore from the same screen.

## Branding

Upload a PNG or JPG logo in Settings → Company branding. Colours default to Otrava primary `#315B65` and dark `#1E3E45`.
